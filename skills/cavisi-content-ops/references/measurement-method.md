# Measurement Method

## Measurement hierarchy

| Objective | Useful signals |
|---|---|
| Awareness | qualified reach, views, audience match |
| Attention | 1-3s hold, completion, watch time, swipe/drop points |
| Education | saves, source clicks, FAQ opens, correct recall |
| Trust | evidence interaction, reduced misunderstanding, qualified questions |
| Consideration | product/system page visits, role exploration, inquiries |
| Conversion | approved commerce events, leads, purchases, assisted conversion |
| Loyalty | repeat engagement, repeat purchase, permitted UGC/referral signals |

## Analysis sequence

1. Restate the original objective and primary KPI.
2. Record observed values without interpretation.
3. Compare with a valid baseline, target, or variant.
4. Identify data limitations: distribution, sample size, spend, seasonality, audience mix.
5. Diagnose likely layers, not a single certain cause.
6. Recommend the smallest useful next test.

## Rules

- Views alone do not prove education, trust, or conversion.
- Engagement rate alone does not prove positive sentiment.
- One winning post does not validate a pillar.
- Comments are qualitative evidence, not representative market truth.
- Do not invent benchmarks when no baseline is supplied.
